### MASTER PROMPT: INFINITY ADS AGENCY WEBSITE BUILD

**Project Vision:** 
Build a high-end, conversion-optimized digital marketing and media buying agency website for "Infinity Ads." The theme is "Cyber Growth"—a dark, technical dashboard aesthetic featuring glassmorphism, 3D visual storytelling, and cinematic video backgrounds.

---

#### 1. CORE TECH STACK & GLOBAL CONFIGURATION
- **Framework:** Tailwind CSS via CDN.
- **Typography:** 
  - Headings: `Outfit` (sans-serif)
  - Body: `Inter` (sans-serif)
- **Primary Color Palette:**
  - Dark Base: `#05070A` (900), `#0F131A` (800)
  - Brand Blue: `#1D4ED8` (Royal Blue)
  - Brand Gold: `#D97706` (Muted Gold)
- **Global UI Rules:**
  - **Glassmorphism:** Use `.glass` class (bg: `rgba(255,255,255,0.02)`, backdrop-blur: `12px`, border: `rgba(255,255,255,0.05)`).
  - **Hero Sections:** All pages use `images/hero-bg.mp4` as a background video (opacity `0.6`) with a gradient overlay (`#05070A` to transparent).
  - **Interactive:** Use hover-scale effects on all cards and buttons.

---

#### 2. GLOBAL COMPONENTS
- **Header:** Sticky navbar with glass blur. Logo size `h-11`. Nav items: Services, About, and a "Let's Talk" pill-shaped button in Brand Blue. Mobile menu uses a slide-in side panel with a 2xl backdrop blur.
- **Creative Footer ("Infinity Systems"):**
  - Background: Pure Black (`#000000`).
  - Column 1: Large Logo, "Systems: Operational" status with a pulsing emerald dot, and "Next Epoch: 2026" technical text.
  - Column 2: "Core Units" (Services links).
  - Column 3: "Firm Intel" (Story, Contact, Legal).
  - Column 4: Newsletter capture + "Social Nodes" (Circular containers for FB, X, IG, LI, TG with brand-specific hover glows).

---

#### 3. PAGE-SPECIFIC ARCHITECTURES

**Home Page (index.html):**
- **Hero:** Big bold heading "Scale Smarter. Grow Faster. With Infinityads." using a blue-to-gold text gradient.
- **Stats Grid:** 3-column stats with large numbers (80M+ Ad Spend, 4X ROAS).
- **Service Summary:** 8 glass cards with platform icons (Meta, Google, TikTok, SEO, etc.) that glow on hover.
- **Growth Engine:** A 3-step section (Uncover, Architect, Accelerate) using staggered glass cards.

**About Page (about.html):**
- **Growth Cockpit Timeline:** A vertical interactive timeline. Central line starts at top-[24rem]. Cards are holographic (glass + scanning light effect). Years (2025, 2024, 2023, 2019) alternate left/right.
- **Values Grid:** A unique 5-column layout (Authentic, Determined, Proud, Relevant, Human). Cards use rounded-[2.5rem] and have specific hover borders (Blue/Gold/White).

**Services Page (services.html):**
- **Detailed Stack:** 8 alternating sections (Meta, Google, TikTok, Media Buying, Affiliate Marketing, PPC, Snapchat, SEO).
- **Layout:** Text description on one side (with bulleted feature lists), and a large cinematic image container (h-[400px] or h-[500px]) on the other with a floating "Category Name" (e.g., "META") in high-transparency text.

**Contact Page (contact.html):**
- **Inquiry Terminal:** Glass contact form with a direct integration to Formspree (action="https://formspree.io/f/mnjblwzj").
- **Features:** 
  - Async JS submission handler.
  - Button state changes to "Processing..." with a spinner.
  - Feedback text: "Target Locked. Inquiry Sent Successfully." (Emerald) or "Connection Error." (Red).
- **Contact Blocks:** Phone, Email, and Address blocks with custom circular hover-scale icons.

---

#### 4. TECHNICAL & CSS EXTRAS
- **Animations:** 
  - `blob`: For ambient background glows moving behind the text.
  - `scan`: A linear light beam moving top-to-bottom inside holographic cards.
- **Utilities:** Add `perspective-1000` and `perspective-500` to parent containers for 3D card tilt effects.
- **Mobile First:** Ensure all text scales down for screens smaller than 380px (specifically .hero-title).
